Key Capabilities

Engineered for Precision & Real-Time Performance

Every algorithm is finely calibrated with Exponential Moving Average (EMA) smoothing and state-machine hysteresis for rock-solid accuracy.

👤

3D Head Pose Estimation

Calculates Pitch, Yaw, and Roll Euler angles in real time using OpenCV's Perspective-n-Point (PnP) solver with custom 3D facial model anchors.

  • Directional State Machine (Up, Down, Left, Right)
  • EMA Jitter Suppression (α = 0.3)
  • Hysteresis thresholding to prevent double counts
👁️

Cartesian Iris Gaze Vectoring

High-precision iris center localization normalized to individual eye contours with dynamic zero-point baseline adaptation.

  • Sub-pixel iris center detection
  • Adaptive dynamic baseline tracking
  • Directional state hysteresis (Left, Right, Up, Down)
⚡

EAR Blink Detection

Real-time Eye Aspect Ratio computation separating Left, Right, and Synchronous (Both) blinks with consecutive frame validation.

  • Euclidean distance landmark ratio
  • Noise-filtered consecutive frame debouncing
  • Independent left/right eye classification
📊

Live Telemetry & Activity Graph

Live visual stream with dark theme activity graphing tracking cumulative face and eye events across the session.

  • Real-time event logging (Timestamp, Event, Count)
  • Matplotlib-matching visual aesthetic
  • Dynamic session time & FPS counter
💾

Instant Data Export & Capture

One-click multi-format data exports formatted with comprehensive movement summaries and full session chronological histories.

  • Full multi-table CSV & Excel (.xlsx) exports
  • High-resolution screenshot capture
  • Real-time MP4 session video recording
🚀

Zero-Base64 Binary Streaming

Custom binary packet protocol transmitting raw packed JPEG frames and JSON telemetry headers with sub-20ms serialization.

  • Single-slot frame dropping to eliminate latency buildup
  • WebRTC native video track support via aiortc
  • Thread-safe isolated multi-user sessions
